================================================================================
HOW TO RUN
================================================================================

1. Source ROS2 and workspace:
   ------------------------------------------------------------------------
   source /opt/ros/humble/setup.bash
   source /media/monder/Files/robotics/project_phee/ros2_moveit_docker/ros2_ws/install/setup.bash
   ------------------------------------------------------------------------

2. Launch the C++ node:
   ------------------------------------------------------------------------
   ros2 run spraying_pathways magnesite_conveyor_ros_node
   ------------------------------------------------------------------------

3. Required ROS2 topics (same as Python version):
   - /camera/camera/color/image_raw
   - /camera/camera/aligned_depth_to_color/image_raw
   - /camera/camera/aligned_depth_to_color/camera_info

4. Published topics:
   - /magnesite_target      (geometry_msgs/PointStamped) -> 3D target in camera_color_optical_frame
   - /magnesite_alerts      (std_msgs/String)            -> verification line alerts

================================================================================
KEYBOARD CONTROLS (OpenCV window)
================================================================================

   q / ESC   Quit
   t         Draw trigger line (click 2 points)
   v         Draw verify line (click 2 points)
   + / =     Increase zoom
   - / _     Decrease zoom
   i / I     Increase inference resolution (+64, max 1280)
   d / D     Decrease inference resolution (-64, min 320)
   h         Show controls help

================================================================================
TROUBLESHOOTING
================================================================================

- If ONNX Runtime is not found during build:
    Ensure deps/onnxruntime/ exists and contains include/ and lib/ folders.
    If missing, re-download from:
    https://github.com/microsoft/onnxruntime/releases/download/v1.19.2/onnxruntime-linux-x64-1.19.2.tgz

- If camera topics are different on your system:
    Edit the topic strings in the constructor of MagnesiteConveyorNode:
      /camera/camera/color/image_raw
      /camera/camera/aligned_depth_to_color/image_raw
      /camera/camera/aligned_depth_to_color/camera_info

- To rebuild after code changes:
    cd /media/monder/Files/robotics/project_phee/ros2_moveit_docker/ros2_ws
    colcon build --packages-select spraying_pathways --cmake-args -DCMAKE_BUILD_TYPE=Release
